# Contributing

This is an early-stage private UI prototype. Contributions will be welcomed once the repository is made public and the open-source licence and development process are finalised.

When proposing changes, preserve the chart-first, minimalist, no-gradient design; keep features optional rather than filling the main screen with controls. Open an issue before large architectural work. Avoid adding trackers, API keys or restrictive dependencies.

Run `python3 -m unittest discover -s tests -v` before submitting any code changes.
